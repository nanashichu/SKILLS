# 上市公司数据经验（CSMAR 等）

仅适用于 A 股上市公司研究；城市、个人、非上市企业等研究对象不套用。来源为早期股价崩盘风险、数字化与供应链项目的经验，数值范围是参考而非硬性标准。

## 1. 股票代码 stkcd

合并用字符串，回归用数值。

```python
# 合并数据时：字符串并补零
panel['stkcd'] = panel['stkcd'].astype(str).str.zfill(6)
# 生成最终面板时：数值型 stkcdcode
panel['stkcdcode'] = panel['stkcd'].astype(int)
```

```stata
xtset stkcdcode year
reghdfe y x $CONTROLS, absorb(stkcdcode year) vce(cluster stkcdcode)
```

- `stkcd`：字符串，如 "000001"，用于合并和显示。
- `stkcdcode`：数值，如 1，用于 `xtset`、固定效应和聚类。

## 2. 样本筛选

- 金融行业（I64 金融业、I65 资本市场服务）和 ST/PT 企业在 00 构建面板时剔除，不作为稳健性检验；下游 do 不再重复剔除。
- ST/PT 识别：合并年度基本信息表的 shortname，`strmatch(upper(shortname), "*ST*") | strmatch(upper(shortname), "*PT*")`，覆盖 *ST、ST、S*ST、PT 等变体。
- 每步 drop 前后 `count`，并在项目 CLAUDE.md 的样本筛选表登记删除数。
- 供应链数据：`statetypecode == "1"`（合并报表），且为上市公司或关联公司；关联公司用 `!missing(isrelatedcompany)` 判断（1=联营，2=合营，3=子公司）。

## 3. CSMAR 字段与单位

| 字段 | 含义 | 处理 |
|------|------|------|
| A100000 | 总资产 | 规模 `size = log(A100000)` |
| D100000 | 经营活动产生的现金流量净额 | 不是负债 |
| T30100 | 资产负债率 | 已是比率，不再相除 |
| T40401 | ROA | 已是比率 |
| T40801 | ROE | 已是比率 |
| Ysmvttl | 总市值 | 单位千元，×1000 → 元 |
| ToverOsM | 换手率 | 单位 %，÷100 → 比例 |

字段含义以 CSMAR 数据字典为准，用前查文档确认。

## 4. 控制变量合理范围（股价崩盘风险研究）

参考《机构投资者抱团与股价崩盘风险》（中国工业经济，2019）。用于描述性统计后检查量级和单位是否出错。

| 变量 | 含义 | 合理均值 | 合理标准差 | 计算 |
|------|------|----------|------------|------|
| NCSKEW | 负收益偏态系数 | -0.4 ~ -0.2 | 0.6 ~ 0.8 | CSMAR |
| DUVOL | 收益上下波动比率 | -0.3 ~ -0.1 | 0.4 ~ 0.5 | CSMAR |
| Size | 总资产自然对数 | 21 ~ 23 | 1.0 ~ 1.5 | ln(总资产) |
| Lev | 资产负债率 | 0.4 ~ 0.5 | 0.2 ~ 0.25 | 总负债/总资产 |
| ROA | 总资产报酬率 | 0.03 ~ 0.05 | 0.05 ~ 0.08 | 净利润/总资产 |
| BM | 账面市值比 | 0.4 ~ 0.5 | 0.2 ~ 0.4 | 账面价值/市值 |
| Sigma | 周收益率标准差 | 0.05 ~ 0.08 | 0.02 ~ 0.03 | 年度周收益率标准差 |
| Ret | 平均周收益率 | 0.002 ~ 0.005 | 0.008 ~ 0.015 | 年度周收益率均值 |
| Dturn | 换手率年度变化 | -0.2 ~ 0.2 | 0.3 ~ 0.5 | 月均换手率差分（比例） |

常见计算错误：

| 变量 | 错误 | 正确 |
|------|------|------|
| BM | 市值单位搞错 | `book_value / (market_cap * 1000)`（市值为千元） |
| Sigma | 用日收益率年化 | 用周收益率标准差，不是日收益率×√252 |
| Dturn | 换手率当成比例 | CSMAR 换手率是 %，先除以 100 |
| Ret | 用日收益率均值 | 用周收益率均值 |

崩盘风险项目的控制变量约定：被解释变量为 DUVOL 时，滞后崩盘风险控制仍用 `L_NCSKEW_Mdeq`，不换成 `L_DUVOL_Mdeq`。

```stata
global CONTROLS L_NCSKEW_Mdeq L_sigma L_ret L_dturn L_size L_lev L_roa L_bm
```
