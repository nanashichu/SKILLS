## 1. 锁定现用链及工作范围

先从本项目当前README定位真实工作根，再读其CLAUDE.md中的现用主程序和数据构建入口，并区分当前估计与保留的历史来源。开始任务时交叉读规则、代码、实际输出；不能仅凭文件名或附近列确定变量和规格。

现用主Y是ratio百分比，匹配阈值0.50、2011—2022、当期C8、城市/年份FE和城市聚类。司法模型保留固定区域聚类，多期DID使用各自原生命令。20261006链剔除北京、上海及广东非深圳城市，主样本274城、3280行；这些是本项目当前实例。

可复用记录：研究对象与主键、Y分子/分母/单位、处理时点与管辖、变量来源与时间、样本窗与排除、FE/聚类/权重、任务范围。先用已有冻结DTA/CSV及来源记录定位变量，不为查询单列重扫全国底库。

## 2. 调整变量：定义、尺度、支持一起核对

每次调整先写“原变量→新变量、公式、来源、时点、单位、受影响模型、样本变化、理论理由”。改Y时同步标签和解释；改M时同步M主项和DID×M；改时间口径时从真正的当期/滞后来源构造，不能重命名列。

本项目面板构建do展示从全部申请人0.50阈值企业数据到城市分子、分母、政策、当期C8、缩尾和模块合并。从构建链检查来源、主键唯一性、零值与缺失，而非只检查最后一张DTA的列名。

| 项目中遇到的调整 | 提取的方法 |
|---|---|
| ratio与数量/对数结果 | 区分研究对象与单位；百分比缩放下b与SE同步变化，p值不因换单位变化；数量定义另列 |
| 当期控制变量 | 对照构建do与来源年份，检查合并及覆盖，不能沿用滞后列的标签 |
| 城市管辖排除 | 保存制度依据和名单，全期排除；保持被冻结的变量尺度，只改变指定支持；重新PSM匹配 |
| GDP/VC递进三列 | 使用本组固定完整样本，逐列检查e(sample)，避免加入变量同时更换样本 |
| 2016年分组或尺度 | 新样本复查沿用已冻结阈值与尺度；是否属于政策前要核对具体制度与主体 |
| GDP支持少32行 | 输出差异ID；共同3114行变量最大差异约3.6e-15，再在同样本估计定位变化原因 |

共同样本用于识别“加变量”与“换样本”的影响。实际e(sample)还会受到singleton删除等估计行为影响；不能只凭complete-case候选样本推断最终估计样本。缺失支持如2015年法律指标全缺时保留无支持状态，不为获得显著结果补造分组。

## 3. 如何寻找有依据的显著结果

项目实际做法是盘点候选口径、冻结计划、完整重估、比较新旧、检查支持与失败，再判断可解释的证据。显著性不是必须交付的数值；“得到了显著”不能替代识别、定义和来源验证。

1. 先排查测度和代码：单位、时间、聚合、处理编码、缺失和重复。修复依据与前后对照一起保存。
2. 检查同一指标的样本、覆盖、处理/对照和FE内信息。GDP支持核对说明同一指标可因32行支持差异改变显著性，不能先归因为指标更好。
3. 理论支持的候选按模块留清单。保存所有正向、负向、不显著、失败与目标项未识别结果；新旧规格兼容才计入“原不显著、现显著”。旧p缺失不属于旧结果不显著。
4. 另外检查识别和安慰剂支持。本项目城市排除后仍有政策前第2期偏离；空间安慰剂支持退化为一城，出现显著信号不能写为识别改善。
5. 使用完整披露和多重检验判断探索线索；正式结果更新需要有明确的定义和设计依据。

### 检验状态与BH

执行前清单与结果按model/module一对一连接。20261006复查记录1632项、1601项成功、31项失败，1601个真实样本文件。原生返回码含498（目标项未识别）、2000（无完整支持）、430（原迭代上限下未收敛），不能填作p=1或写为检验通过。

实际汇总代码按模块全部规格、事前primary主检验、全局全部规格分别做BH。**每个family只对有限p计算，分母为该family有效p数；失败项的p/q均保留缺失。** 同时公布计划数、成功数和失败数，避免以校正后列掩盖失败。不能把结果出来后的显著项改标primary。

[规格汇总模板](../scripts/汇总规格检验_模板.py)移植该BH函数；接口为每个计划目标项一行CSV，必需model/module/term/b/se/p/rc，可带primary和旧结果/来源/样本字段。它只汇总，不运行估计；全部系数和正式线性组合仍由原生估计另行保存。

输出接口：`--output-dir data/temp/YYYYMMDD_数据主题 --receipt 测试/分析类别/YYYYMMDD_任务/运行ID_核验回执.json`。两份CSV始终在原data/temp数据位置，回执在原任务包，采用不复制数据；连续汇总复用原数据目录，输出不变则读取已有结果，确需替换先保留被替代记录，不为绕过防覆盖检查另建日期任务包；脚本在读取输入前拒绝初稿路径、覆盖已有输出、数据分层错误和输入输出冲突。以上历史项目路径只作来源定位，实际输出以当前目录边界和现场核验为准。

## 4. 交互、异质性与抑制性检验

连续模型分别报告DID、M与DID×M的b/SE/p、M单位、N、FE和聚类。给定M=m的政策效应是β+θm；DID=1时M斜率是γ+θ。M的负主项不能替代交互解释。

固定高组H模型中，低组=β、高组=β+θ、差异=θ。项目复查使用完整交互规格和聚类Wald，保存高组lincom与正式差值；不能把两组各自的显著性当成差异检验。详细示例见[组间差异](group-difference-test.md)。

保留用户采用的“抑制性检验”术语，明确政策×政策前连续变量的构造和估计对象。司法代理、政策对M的影响、M的调节作用是不同证据，需按各自定义解释。

## 5. 逐表do、真实样本与独立核验

本项目主程序调用真实的01—16逐表do及图9—10程序；表格按文稿表序与模型清单映射。表内全部模型、控制、FE/聚类、原生导表命令、样本保存和日志依赖都有实际实现，不能用空白do代替已运行的模型。

每次Python估计立即保存完整b/V、推断设定及实际使用的样本主键，核对N、城市数与样本范围；stacked样本加stack/批次维度。最终Stata核对再保存.ster与真实e(sample)。dCDH按各期实际支持报告，不以全样本生成伪ID。保存估计便于重新导表，但不能替代输入、构造与估计方法来源。

批量失败时立即记录失败状态；成功后才读取结果，避免失败沿用上一模型结果。（该项目当时在Stata中用_rc记录；现行规则do中不用capture，需要容错的批量估计在Python中完成并保存失败状态。）技术修复和续跑保留记录，合并核验计划ID唯一性、缺项和完成总数。

普通线性FE斜率核验从原生实际样本回到输入，对Y及全部X按相同FE/权重交替去均值，再OLS。项目复查19项FWL核验最大系数误差约1.18e-12。[FWL模板](../scripts/核验固定效应系数_模板.py)提取该算法；只核验斜率，不核验聚类SE/p或替代动态DID命令。

## 6. 完整结果Word、三线表与R²

本项目04号程序从指定稿件复制页面设置和表格XML，再填入本轮表数据；表序来自文稿结构与模型映射。当前结果Word表内9pt，英文Times New Roman、中文仿宋，左右各2.286cm、上下各2.159cm。表格使用固定布局和原稿列宽，三线格式保存在单元格边框中。

这些是**当前参考文件的实测设置**。可复用模板必须读取指定Word，而不是硬编码旧规则或把本项目的尺寸推广到其他研究。标题、表注、表格、模型ID与图形按清单组织；项目结果汇编包含16表及2图，数量不写死进模板。操作见[导出指南](report-generation.md)。

只补R²：本项目14号程序读取保存的原生估计与SA底层回归，提取esttab命令重新导出；不运行估计命令。项目要求包含FE的总体R²、四位小数，不能以within/调整R²替代；CS/did2s/dCDH原生命令无常规R²时“—”并解释。核对b/SE/p/N未变、R²与保存对象一致、表格除新增行外一致、原输入指纹未变。
