# 实证研究

## 0 优先级与适用边界

- **规则优先级：** 用户本轮明确指示 > 项目 README、CLAUDE 与实际设置 > 本 skill > references、scripts 与模板。references、旧模板或历史 memory 中与本文件冲突的旧说明（自动删文件、写入初稿、固定版式、先跑 do 等）一律以本文件为准。
- **分工：** 本 skill 管计算、结果汇报、图表与导出；项目初始化、目录迁移、归档和清理按 empirical-project-init。下文“共享规则”与该 skill 的同名一节保持一致，修改时两边同步。
- **项目实例只作方法说明。** 经验取自知识产权法庭与发明家创业项目；样本、城市名单、变量尺度和文档版式在其他项目中重新读取，不设为默认值。

## 1 开始工作

1. 从项目 README、CLAUDE 和实际设置确认唯一工作根（不把对话 cwd 当输出根）；读取用户确认稿件、现用主程序、模型结果和运行日志。
2. 判断本轮类型：新估计、变量调整、规格筛选、结果复查、补统计量、只导出，或只改 skill/排版。后三类不含重新估计。
3. 按 S2 定位原任务包；列出全部真实输出路径（旧程序默认路径、相对路径基准、旁路回执、缓存、渲染），确认不写初稿、不写到参考 Word 旁边。
4. 写明 Y 及单位、DID 与政策时点、控制/调节变量时点、样本支持、FE、聚类、权重，并标出本轮实际改变的部分；换变量时记录定义、来源、样本变化及受影响模型。
5. 按第 3 节用 Python 估计并全量保存 → 按第 2 节总结 → 用户明确要求时按第 5 节导出 → 研究版本确认后按第 6 节做 Stata 核对。

## 2 结果汇报：先总结，全量保存

**对话总结**（不默认铺开全部结果）：

1. 一句结论：核心效应方向与显著性是否成立。
2. 显著组合：少量代表规格的核心系数、SE、p、实际 N、FE、聚类口径；默认按 S9（四列、统一样本、一步法机制）组织。
3. 较优设定及理由：区分系数变化、聚类改变带来的精度变化、样本变化、事前趋势和多重检验，不按最小 p 认定“最合理”；动态结果报告联合检验与主要形态。
4. 不显著、反向、失败、未估计：如实列出，失败不等于不显著。
5. 关键诊断与风险，下一步值得尝试什么。
6. 完整底表路径；用户要求时再展开。

**全量保存**（简洁展示不等于只保留显著结果）：每个模型的 Y 及单位、全部 b/V、SE、p、实际 N、企业/城市数、FE、控制、聚类、权重、自由度/小样本修正、R²、动态各期及联合检验、失败状态与原因，连同实际样本 ID、代码、日志和核验回执落盘。“暂不导出”不等于不保存，也不为等待导出指令暂停已授权的估计。

## 3 Python 计算规范

- **范围：** 数据与变量调整、缩尾、样本与 DID 检查、规格筛选、重新匹配、基准/稳健性/机制/异质性、全套重跑、多期 DID、动态效应、置换/安慰剂、特征化事实，以及表图、Word/RTF 和结果对照。已有最终 DTA、参考 Word 或历史 do 时，读取其设定在 Python 实现，不执行旧 Stata 主程序。
- **缺接口不回退 Stata。** 先找可用 Python 实现，必要时自行实现相同估计量与推断；仍无法完成的单项标“未估计/失败”并写原因，其余模型继续。禁止用普通 TWFE 替代 CS、SA、did2s、dCDH 等约定方法却沿用原方法名。ado 方便、实现费事、想做双软件比较都不构成运行 Stata 的理由。
- **实际样本：** 每个模型估计后立即保存估计器真正使用的实体键，计入 singleton、权重、支持窗和方法特有筛选；不能用 complete-case 或基准 ID 冒充其他模型的样本。导表与独立核验直接读取这些结果。
- **口径不随软件改变：** Y/单位、DID 时点、分组/权重、共同样本、FE、聚类、singleton 规则、有限样本修正、t/z 分布保持一致。沿用 winsor2 口径时匹配其百分位定义，不用 pandas 默认线性插值冒充。交互项、比例换算和正式差值从处理后的基础变量重建，不独立缩尾破坏恒等式。
- **加速：** 按真实样本、FE、权重和规格分组复用去均值矩阵及分解；置换复用不变控制与 FE 的投影，固定抽样/置换向量与种子；限制总进程数与 BLAS 线程，避免重复读整份面板。缓存键包含输入指纹、变量变换、样本键和估计设定，任一改变即重算。
- **历史 Stata 结果只读比较。** 不能把历史 Stata 证据写成本轮 Python 结果已通过 Stata 核对。

## 4 图形

- 为本用户生成论文、实证结果和特征化事实图时，**默认不在图内放总标题、副标题或解释性注释**。年份范围、口径、匹配阈值、变量定义与公式、数据来源、缩尾、样本限制、不完整年度及“注：……”写在正文、图外图题/图注或配套说明，不烧录进 PNG/SVG/PDF；用户明确要求某项文字放图内时才添加。
- 保留读图必需的坐标轴名称与单位、刻度、图例、子图编号、简短指标标签及任务需要的数据标签和统计标记。
- 删除说明后同步收紧画布与边距，不留旧标题/注释的空白；曲线、数据、范围和口径不变。
- 导出前查看实际渲染图，确认无标题、注释、来源残留，必要标签无遮挡、无裁切。移出的定义与来源继续保存在说明、底表与核验记录中。此规则不授权生成 Word/PDF。
- 特征化事实由 Python 从冻结输入直接构造逐图数据、绘图并核验，不生成或调用特征化事实 do，也不要求先跑 Stata 产出 CSV。

## 5 文档导出（仅在用户明确要求时）

- 不导出 LaTeX。
- “继续做机制”“开始跑”“重跑全部结果”“看看结果”只授权计算与对话展示，不授权 Word/PDF/RTF，也不把导出列为默认收尾步骤。本轮已明确要求的格式按范围直接导出，不重复询问；要求 Word 不自动追加独立 PDF。
- 只要求导出时，读取本轮已核验的估计与底表，未授权重估就不重跑回归。
- 版式从用户指定的现用参考 Word 读取（当前项目为表内 9pt、Times New Roman/仿宋，左右各 2.286cm、上下各 2.159cm），模板不硬编码这些数值。
- 多时点 DID 替代估计方法稳健性表默认纵排：每种方法一行，五列为“估计方法、政策效应估计值、标准误、效应汇总口径、方法报告的N”，系数星号及 N 脚注上标，表下注明 FE、控制、聚类与各方法 N 口径；数值全部取自本轮 Python 结果。见 [纵排规范](references/multiperiod-did-vertical-table.md)。
- 补 R² 从对应已保存估计读取（Python 对象/底表；历史 Stata 结果可只读 .ster），不重估；CS、did2s、dCDH 无约定常规 R² 时填“—”并说明。只补统计行时验证其余内容不变。
- 按受影响内容做数值、结构与视觉检查；全部实证结果的完整 Word 汇编另按 S5 复制到 `完整实证/`。

## 6 最终 do 与 Stata 核对（仅在研究版本确认或用户明确要求时）

- 触发条件见 S7。确认后冻结本轮输入与设定，生成/同步最终主 do（从原始数据导入写起），运行后用 log 与 esttab 输出核对 Python 的 N、b、SE、簇数、权重和 R²；原生日志留原测试包。
- 高成本置换/bootstrap 不自动在 Stata 重跑，登记已核对与未核对范围。没有实际执行时写“do 已生成，Stata 核对未运行”。
- do 的写法与验收按 S8 和 [stata-do-my-style](../stata-do-my-style/SKILL.md)；目录与主 do 模板见 empirical-project-init。

## 8 项目留下的关键经验

- **先查样本，再解释显著性变化。** GDP 同一测度在共同 3114 行几乎完全一致，定稿支持少 32 行；显著性差异定位为样本支持变化，未按 p 值补填缺失。
- **保留全部检验状态。** 未保留检验复查共 1632 项，成功 1601、失败 31；失败不是不显著，政策前偏离不能随显著结果一起隐去。
- **交互报告完整。** DID、M、DID×M 分别输出；固定高组效应是主项与交互之和，差异是交互项，用完整协方差检验。
- **真实样本是核验入口。** 不同模型不能共用基准 ID。
- **保存支持边界。** 动态估计、司法代理、登记快照、末年覆盖含义不同，数值显著不能替代定义与识别核查。

## 共享规则（与 empirical-project-init 保持一致）

### S1 工作根与初稿

- 唯一工作根以 README、CLAUDE 和实际设置共同指向的真实路径为准，skill 不硬编码项目目录。已授权迁移时同步路径与入口，不重复索要同一授权。
- `初稿/` 是作者论文区，AI 只读；只有用户指定具体稿件及编辑范围时才操作。导出、确认结果、采用均不授权写初稿。读取参考 Word 时不在其旁边写任何文件。

### S2 任务包：先复用，后新建

- 位置：`测试/分析类别/YYYYMMDD_主题/`。“分析类别”是占位：先判断本任务内容属于哪一类，再放进该类别的文件夹（例如做异质性相关的任务就放 `测试/异质性分析/`）。七个固定类别：**特征化事实、异质性分析、机制、基准、稳健性检验、进一步分析、初稿整理**；不创建名为“分析类别”的文件夹，类别层不加日期，不新增第八类。
  - 特征化事实：描述性事实、趋势、地图、行业或资本分布及其图形调整。
  - 异质性分析：分组、交互项、行业及企业特征差异。
  - 机制：机制变量、渠道及该机制自身的样本、控制、聚类、平行趋势诊断（标题含“稳健”也不拆出）。
  - 基准：主分析面板、主 Y 与处理变量构建、基准估计及口径核查。
  - 稳健性检验：主结果的替代口径、缩尾、样本敏感性、识别与影响诊断。
  - 进一步分析：扩展问题、额外结果变量及补充调查。
  - 初稿整理：稿件文字与表格整理、政策背景、跨章节整套汇编、版本核查、目录/文件/skill 管理（AI 工作区，区别于根目录 `初稿/`）。
- 一个包只归一个主要类别；跨章节完整包整包放初稿整理，不按文件类型或表号拆散。无法判断时先读任务说明与输出对应关系，仍缺影响归属的信息才询问。
- 两张现用清单（文件清单.csv、图表对应.csv）只放唯一文件管理包 `测试/分析类别/YYYYMMDD_文件管理/`（包名即 `{{MANAGEMENT_TASK}}`），README 链接这一处，只在原位置更新。文件管理按类别定义（目录/文件/skill 管理）归入初稿整理，所以实际路径在 `测试/初稿整理/` 下。
- 同一研究问题的跨天/跨对话继续、表图微调、补统计量、同问题控制或参数诊断、核验、导出、采用、修复、重跑，**都沿用原包与原开始日期**。只读查询、解释、盘点不建包、不写回执。只有“新的独立研究问题 + 无可复用包”才新建。
- 每包一份任务说明（范围、状态、输入输出、检查）；新运行日志用运行 ID 命名；仅并行运行或大量中间文件需要隔离时才建包内运行子目录。
- 日志、诊断、核验回执、渲染预览、来源与采用记录始终留原测试包，采用不迁走；项目根不建 `logs/`。
- 分类本身不代表采用，不授权重估、导出或删除。

### S3 数据集中在 data

- `data/raw/`：外部原始来源，只读。`data/temp/`：构建数据、共享中间层、候选/现用分析面板、回归底表、估计对象、b/V、实际样本 ID、高成本缓存；任务专属数据可放 `data/temp/YYYYMMDD_主题/`。`data/final/`：现用最终面板和明确冻结的版本。目录位置不表示采用状态，状态在清单中登记。
- 同一可复用数据只保留一个现用物理副本，跨任务只读引用，不随测试包复制；测试包登记真实路径、版本、指纹、生成代码、状态与调用关系。共享大库只登记，不复制。“完整任务包”指完整可追溯链，不是复制全部数据。
- 去重依据 SHA256 或完整结构/数值核验；同名但样本、定义、参数或实际支持 ID 不同的文件不是重复。
- **现用面板只增列时可原位替换**，须全部满足：面板主键唯一且一对一对齐，键集合、行数、样本/年份范围相同；全部原有列逐项核验值、缺失状态、编码/类型、尺度及标签未变；只新增原面板没有的列。禁止覆盖同名列、增删行、改排序对应、只抽查部分旧列或用宽松容差。通过后在 data 内保留替换前原字节与哈希（如 `data/temp/YYYYMMDD_面板增列/原面板归档/`），先写暂存面板并回读核验再原子替换，登记新增列、匹配覆盖率、前后指纹、备份位置。任何旧列、主键或样本变化则另存候选，不替换。补列不使原结果失效，也不自动重估、采用新变量或导出。冻结历史版本只读。

### S4 命名

- **目录**：任务包、采用项、结果版本、归档一律 `YYYYMMDD_主题`，同日重名用 `YYYYMMDD_HHMMSS_主题`；禁止“主题_日期”。日期取任务实际开始日，继续沿用原日期，不以整理日替代；无可靠日期先查日志/来源，仍不明标“待确认”，不编造。建目录前列出完整目标路径核对，收尾再查一次。固定用途目录（data、raw、temp、final、do、code、result、table、figure、测试、归档、初稿、完整实证）及包内用途分类不加日期。
- **阅读与分享产物**：Word、PDF、RTF、Excel、PPT、可分享图片用 `YYYYMMDD_主题.扩展名`；单表/单图如 `20261010_表13_城市VC获投企业家数.docx`；Word 与配套 PDF 同主名；文档核验回执为 `<主名>.核验.json`。文件日期是该产物的生成/修订版本日，采用、迁移、归档不改写。同名更新先归档，不堆“最终版/修复版”。
- **其他文件**：现用代码以两位工作序号开头；机器底表、估计对象、样本 ID 按模型 ID 或阶段命名；渲染页图与缓存保留工具编号，放对应文档的核验目录；原始来源、作者稿件、历史日志/回执/测试输入保留原名。
- **改名/迁移**：先登记准确映射、检查重名和依赖，同步现用程序、导出器默认值、模板、README 与两张清单；历史日志和回执保留原字节，通过映射回查。

### S5 采用与入库

- 采用只来自用户明确表态（“这个结果可以用”“采用表13第2列”）。“挺显著”“看看”“继续做”、构建完成、导出成功、验收通过、文件名含“最终”都不是采用。
- 按范围提取最小完整复现链：数据复用 data/temp 中已登记的位置，不再复制；Python 源码与必要配置进 `code/`；`.do` 进 `do/`；已采用且获授权导出的排版表进 `result/table/`，图进 `result/figure/`。部分采用只提取指定模型及必要依赖。未采用的代码和表图不进现用目录。
- 采用不触发重估、改模型或扩展导出格式；单项采用不等于整个研究版本确认。
- 登记采用范围、源/目标、指纹、模型设定、实际样本和调用方式，更新清单；原测试包保留，其中显著/不显著/负向/失败状态继续可查。
- **`完整实证/` 阅读副本**：每次用户授权生成全部实证结果的完整 Word 汇编并完成核验后，另复制一份到 `完整实证/`（只放完整汇编 docx，不放单表、PDF、底表、脚本、回执）。它不表示采用。复制前同名同哈希则复用，内容不同先归档再复制，禁止静默覆盖；复制后核对 SHA256 并登记源/目标与版本。汇编单独登记所含各表版本及尚未合并的采用项；单表更新后，旧汇编及其副本不能称为最新版。此规则不触发生成。

### S6 最小留痕、备份与清理

- 同一授权修改任务内，每个源文件首次编辑前保存一次原字节与哈希，后续微调复用该基线。被替代的正式结果、数据与代码版本留可恢复归档（`归档/YYYYMMDD_正式vNN/`）。
- 真实运行日志、已出具回执和冻结证据不改写、不静默删除；修正写进当前说明并引用旧记录。
- 核验只生成必要材料：复用仍匹配当前文件的已有证据；图形微调只看论文尺寸最终输出；文档导出按受影响内容检查；不机械生成整套验收副本、拼图、解包或额外格式。渲染放原包既有预览位置，历史证据不覆盖。
- 删除已有文件：准确清单 → 用户确认 → 隔离到 `YYYYMMDD_待删除/` → 相应复现通过 → 删除。任何规则都不自动清理历史文件。
- 修改 README、CLAUDE、skill 或模板时改原段并消除冲突，一条规则只保留一个权威定义，不在文件头追加“最新补充”；必要的历史规则作一次原件快照。
- 历史混合源包和仍被调用的上游代码模块登记后可保留内部相对布局，不为平铺而拆散，也不复制第二套；不得把新日志、图表写进代码/数据区。

### S7 计算、展示与导出的授权边界

- 日常计算与结果交付只用 Python。只有用户确认**整个研究版本**（“确定用这一版”“研究设定已经定了”或同义）后，才冻结输入与设定并生成/执行最终 do 核对；用户直接要求 Stata/do 核对时按其范围执行。“重新跑所有结果”“导出这个表格”“生成最终面板”、路径含“定稿/最终版”、旧版本曾被采用，都不是版本确认。
- 结果跑完先在对话总结；只有用户明确要求才生成 Word、PDF、RTF 等排版文档。最终版本确认、生成 do、Stata 核对都不自动授权导表。

### S8 最终 do 写作与验收（仅核对阶段适用）

- **写法以 [stata-do-my-style](../stata-do-my-style/SKILL.md) 为准**：一个项目一个主 do（模板见 empirical-project-init 的 `templates/do/论文名_主程序.do`；多个项目共用的原始库清洗可另放一个数据处理 do），从原始数据导入写起，按“导入数据 → 处理数据 → 回归分析 → 异质性 → 机制 → 稳健性”用五行横幅和 `**#` 书签分节；路径用 `$path1 $DR $DT $DF`，控制变量用 `global 控制变量`，回归用 `reghdfe` + `est store` + `esttab`。
- **不写**：`program define` 助手（ensure_dir、next_log、start_run、record_result、save_sample_ids 等）、mata/frame/postfile、`01_统一设置.do` 加逐表拆分和只会挨个 `do` 的主程序、`isid`/`assert` 检查墙、冻结输入加 sNNN 样本标记、文件头后的目的/步骤/时点/边界大段说明、在 do 里保存 .ster、b/V 或 Python 参考差值。
- **口径照样可追踪**：Y、X、控制、样本筛选、FE、聚类与 Python 确认版一致。变量构造写在 `/*======变量名========*/` 小标题下，旁边用 `//` 注明原始字段含义、公式、单位和来源；merge 写清来源文件与键，后跟 `drop if _merge==2`、`drop _merge`，必要时 `tab _merge` 的结果用 `//` 贴在下面。只有 Stata 做不了的步骤（如文本分析、爬虫）才导入 Python 生成的中间文件，并注释生成脚本的位置。
- **分节可单独运行**：每个分析小节以 `cd $DT` + `use 面板,clear` 开头，运行文件头路径段后即可单独运行该节；数据切换写成 `save` + `use`，不用 preserve/restore。
- **样本**：回归前按第 4 列所需全部变量非缺失和筛选条件生成 `egen nmiss=rowmiss(Y X $控制变量)` + `gen sample=1 if nmiss==0&筛选条件`，四列及后续各节统一 `if sample==1`；Python 侧保存的逐模型真实样本 ID 用于核对，不写进 do。
- **结果核对在 do 外完成**：运行后读取 log 与 esttab 输出，与 Python 底表逐项比对 b、SE、N、簇数、R²，差异记在原测试包的核对说明里。
- RTF 等导出段默认注释，只有用户授权相应表与格式后才启用；特征化事实不生成 do。
- 不得用历史生成脚本或快照覆盖整改后的现用 do；改名同步图表对应清单，旧版归档保留原字节。
- **验收**：新开 Stata 会话从头运行主 do（或运行路径段后单独运行对应小节）；逐项报告已改、实际运行通过、尚未验证的范围。只改注释时逐行核对可执行命令不变；静态检查不能称为复现。可读性测试：不依赖本次对话的读者能从 do 里看出原始数据从哪来、Y 怎么算、控制变量是什么、样本怎样筛。

### S9 默认研究设定（项目另有要求或用户说明时以其为准）

- **基准回归默认四列**：(1) 无控制无FE (2) 有控制无FE (3) 无控制有FE (4) 有控制有FE（首选）；不同项目的列数以稿件和项目 CLAUDE.md 为准。
- **统一样本**：各列及后续机制、稳健、异质和描述性统计默认使用同一样本（第 4 列所需全部变量非缺失，do 中为 `sample == 1`）；偏离由用户说明，并在表注和图表对应清单登记。Python 估计同样以此为默认样本，并照常保存每个模型的真实样本 ID。
- **机制检验默认一步法**：只估计 X 对当期机制变量 M 的影响；不把 M 放进基准回归，不做第二步，除非项目另有要求。
- **控制变量宏**统一为 `global 控制变量`，全项目引用 `$控制变量`。
- **Stata do 不用 capture 掩盖报错**；只在文件头建目录时用 `cap mkdir`。
- **回归表保留常数项和控制变量系数**：esttab 不用 `keep()`、`drop(_cons)`。
- **样本删除可追溯**：raw 只读；构建面板时可以 drop，但每步前后记录 N 与删除数，登记到项目 CLAUDE.md 的样本筛选表。
- **不导出 LaTeX**；排版文档按 S7 只在用户明确要求时生成 Word/PDF/RTF。
