**现行规则（2026-10-10）**：用户明确要求后才导出指定文档，结果Word默认放测试/分析类别/YYYYMMDD_主题。完整底表、估计对象、实际样本、代码、日志和核验记录继续按int规范保留；旧“只保留docx、删除其他格式”条款已废止。初稿默认只读，文件扩展名不是删除依据。

**命名格式**：`【日期】文件内容.docx`

示例：
- `【20260423】描述性统计.docx`
- `【20260423】基准回归.docx`
- `【20260423】分位数回归.docx`

**Why**：统一命名格式便于按日期追溯版本，docx格式便于直接查看和编辑。

**How to apply**：在用户授权导出时按项目实际命名，格式示例不触发导出；已有文件清理须先查依赖，准确清单确认、隔离、验证后删除，不按扩展名自动删除。
