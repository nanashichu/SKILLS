# 06 进一步分析

## 1 顶刊常见做法

### 中文常见内容

| 类型 | 做法 |
|---|---|
| 经济后果 | X 带来的 Y 变化是否进一步影响企业价值、全要素生产率、绩效、融资成本等 |
| 动态与持续性 | 效应在处理后各年的变化；短期与长期 |
| 调节因素 | 外部治理（分析师、机构投资者、媒体）、制度环境（市场化、法治）对主效应的强化或削弱 |
| 溢出效应 | 同行、供应链、同地区、同集团企业受到的间接影响 |
| 非线性与门槛 | 二次项、分位数回归、门槛回归（Hansen 1999, JoE） |
| 空间溢出 | 空间计量模型；空间相关的标准误（Conley 1999, JoE） |
| 市场反应 | 事件研究法累计超额收益 CAR |
| 替代或互补关系 | 如应计盈余管理与真实盈余管理是否此消彼长 |
| 成本收益 | 粗略测算政策净效应或福利含义 |

### 英文

- 区分广延边际与集约边际；
- 实际效应（real effects）：从报告层面延伸到投资、雇佣、融资等决策；
- 溢出与一般均衡：对照组受到溢出时，基准 DID 估计有偏（违背 SUTVA），应回到识别讨论，而不是只作为“进一步发现”。

## 2 审稿人常挑的问题

- 进一步分析过多，稀释主线；
- 与机制部分混淆（同一结果既叫机制又叫经济后果）；
- 溢出效应显著却没讨论它对基准估计的偏误；
- 经济后果分析中把 Y 当解释变量，内生性没处理。

## 3 不显著时可借鉴

| 信号 | 做法 | 风险 |
|---|---|---|
| 经济后果不显著 | 本身有信息：说明“未传导到 xx”，或时间窗口不足以观察；可看更长期的结果 | 🟢（报告）/🟡（延长窗口需依据） |
| 溢出效应不显著 | 正好支持对照组未被污染，可放进识别讨论 | 🟢 |
| 调节效应不显著 | 如实报告；不换调节变量的阈值或代理来求显著 | 🟢/🔴 |
| 门槛/非线性不显著 | 说明线性设定足够；不来回试门槛数与门槛变量 | 🟢/🔴 |

## 4 检索关键词

- 中文：进一步分析 经济后果 企业价值；溢出效应 同行 盈余管理；门槛回归；空间溢出；市场反应 累计超额收益。
- 英文：real effects；peer spillovers SUTVA；extensive intensive margin；threshold regression panel；spatial standard errors。
