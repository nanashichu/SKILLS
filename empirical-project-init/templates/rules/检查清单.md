# 检查清单

## 1. 回归前检查

- [ ] 变量是否有缺失值？→ `misstable summarize`
- [ ] 面板是否平衡？→ `xtset` 后检查
- [ ] 关键变量分布是否异常？→ `summarize, detail`
- [ ] 控制变量是否在合理范围内？→ 参照 empirical-research skill §9

## 2. 回归后检查

- [ ] 系数方向是否符合理论预期？
- [ ] 显著性水平是否合理？
- [ ] 观测数是否与预期一致？
- [ ] R² 是否在合理范围（0.05-0.30 为常见范围）？
- [ ] 固定效应是否正确吸收？

## 3. 表格导出检查

- [ ] 标准误是否在系数下方？
- [ ] 显著性星号是否正确（`***` p<0.01, `**` p<0.05, `*` p<0.10）？
- [ ] 观测数 N 是否报告？
- [ ] R² 是否报告？
- [ ] 固定效应是否标注？
- [ ] 三线表格式？
- [ ] 字体：中文仿宋，英文 Times New Roman？

## 4. 数据合并检查

- [ ] merge 后 `_merge == 3` 的比例是否合理？
- [ ] 是否有意外的大量不匹配？
- [ ] 合并键变量类型是否一致（str vs numeric）？

## 5. 常见错误排查

| 现象 | 可能原因 | 排查方法 |
|------|----------|----------|
| 观测数骤降 | 缺失值过多 | `misstable summarize` |
| 系数异常大 | 变量单位问题 | `summarize` 检查均值 |
| 不收敛 | 多重共线性 | `vif` |
| R² 为负 | 固定效应设定错误 | 检查 `absorb()` |
